# 회사별·칼럼별 출처 안내

2512 개발 검증에서 일치한 값과 불일치·빈칸을 모두 포함한 탐색 목록입니다. 정답 수치를 재사용하는 규칙이 아닙니다.

12개사 1560개 회사·칼럼 조합, PDF 직접 확인 165개 조합(166개 근거), 기존 팩트시트 규칙 129개를 기록했습니다.

정답 대조 대상 854개 중 일치 733개, 불일치 55개, 빈칸 66개를 포함합니다. 일치 여부와 출처 검증 수준은 별도입니다. XBRL 추출 묶음만 있는 항목은 정확한 태그·context 위치까지 확인한 것으로 표시하지 않았습니다.

[전체 회사·칼럼 출처 목록](회사별_칼럼별_출처목록.csv) · [121개 불일치·빈칸 분석](2512_불일치_빈칸_분석.csv)

## 사용 기준

페이지는 2512에서 찾았던 위치 예시입니다. 다음 분기에는 표 제목·행 이름·연도·분기 열·각주·단위를 다시 확인합니다. PDF 텍스트와 이미지가 다르면 이미지를 확인합니다. 숫자 반올림이나 발표 시점 차이만으로 기존 정밀값을 교체하지 않습니다.

## 검증 범위

2512 정답을 보고 보완하는 개발 단계입니다. 기존 블라인드 결과는 수정하지 않았으며, 다른 분기 성능 향상을 입증한 결과가 아닙니다. 위치 미확인·정의 미확정 항목은 계속 미해결로 남깁니다. PDF 코드 보완은 별도·단위·기간·표 구조 확인을 대체하지 않습니다.
