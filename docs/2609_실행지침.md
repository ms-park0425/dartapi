# 2026년 9월 입력: ChatGPT 실행 지침

이 폴더를 받은 새 담당자도 같은 절차로 실행한다. 개인 계정의 과거 대화나 특정 PC 경로를 전제로 하지 않는다.
설치·사용 안내와 전체 흐름은 [README](../README.md), 공통 규칙은 [AGENTS.md](../AGENTS.md)를 먼저 읽는다.

사용자가 프로젝트 채팅에서 **“202609 분기보고서 채워줘”**라고 요청하면 2026년 3분기로 해석하고 내부 실행 코드 `2609`를 사용한다. 사용자가 별도로 명령어나 검토 JSON을 작성하게 하지 않는다.

1. 사용자가 이번 요청에 제공한 Excel을 우선한다. 없으면 `quarter_pipeline.read_config()`로 기본·로컬 설정을 합쳐 작업 파일을 확인한다. 이전 담당자의 절대경로가 유효하다고 가정하지 않는다. 전달용 묶음의 작업 파일 이름은 `작업양식.xlsx`이다.
2. `.env`의 DART 키를 사용하고 출력하지 않는다. FISIS는 호출하지 않는다. 작업 사본에서 진행하고 2606까지 기존 값·수식을 보호한다. 정답본은 입력 양식으로 쓰지 않는다.
3. `quarter_pipeline.py --period 2609 --reviewer assistant`로 수집·1차 입력·PDF 검토 자료를 준비한다. 새 작업 파일이면 `--workbook`으로 지정한다.
4. `state.json`, `field_catalog.json`, `current_values.json`, `source_manifest.json`, `collection_issues.json`, `publication_manifest.json`, `review_assets.json`을 확인한다. 실제 제목 `(2026.09)`에 맞는 보고서인지 확인하고 다른 분기 자료를 대입하지 않는다. 미게시 회사는 미게시로 기록한다.
5. `quarterly_lessons.json`, `review_navigation_2025.json`, `company_field_sources.json`을 검토한다. 과거 페이지는 탐색 예시다. 현재 PDF 이미지를 직접 열어 회사 본체·회계 기준·단위·기간·잠정/최종·원수/보유/출재·부호를 재확인한다.
6. 빈칸을 보충하고 기존값도 대조한다. 같은 정의의 정밀값은 유지한다. 기존값 교체는 단위·부호·기간·계정 매핑·추출 오류가 입증된 경우만 허용한다. 다른 원문 숫자만으로 교체하지 않는다. 모호한 기준은 충돌로 남긴다. CALC·CHECK·수식은 채우지 않는다.
7. 실제로 읽은 페이지만 `review_results.json`의 `reviewed_pages`에 기록하고 `findings`를 작성한다. 이것은 ChatGPT의 내부 작업이며 사용자가 작성하게 하지 않는다. 필요한 추가 PDF는 원문·해시·이미지까지 실행 폴더에 등록한다.
8. `quarter_pipeline.py --finalize 실행폴더`로 반영한다. 거절·보류·미해결·검산을 확인하고 고칠 수 있는 문제는 처리한다. 수식 재계산이 남으면 `recalculate_excel.ps1`로 실행 사본만 재계산한다.
9. 최종 Excel, 실제 검토 범위, 남은 빈칸·충돌·미게시 회사, 재계산 상태를 보고한다. 2025년 개발 검증 정확도를 2609 정확도로 표현하지 않는다. 자동 감시나 예약은 설정하지 않는다.

## 특히 구분할 항목

- K-ICS: 회사 본체/자회사, 경과조치 전/후, 잠정/최종. 잠정 값을 최종 칸에 복제하지 않는다.
- CSM: 기초/기말·분기/누계·원수/순보유·출재 차감을 확인한다. 변동식의 차이를 조정항목 역산으로 메우지 않는다.
- 기간별 CSM 83~87: 84·85의 중첩 헤더에 주의한다. 교보 2509는 연결 기준 1~3년·3~5년과 대응했지만 현재 분기에도 같다고 가정하지 않는다.
- 기간별 정의가 확인되면 이번 실행 설정의 `company_fields`에 해당 회사·칼럼만 지정한다. 다른 CSM 칼럼이나 다른 회사의 기준을 전역 변경하지 않는다.
- `unresolved`·`reference_disagreement_unresolved` 지침은 해결된 사실로 취급하지 않는다. 최신 회사별 표와 각주를 확인한다.

`assistant` 명령 종료는 최종 완료가 아니다. ChatGPT가 이미지 검토·수정·저장까지 이어서 수행한다.
